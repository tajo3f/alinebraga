## Itens removidos nesta revisão

- Imagem/guia visual com a lista de procedimentos.
Os procedimentos permanecem apenas em conteúdo HTML estruturado e páginas próprias.

## Segurança
O projeto inclui CSP estrita, HSTS, bloqueio de framing, nosniff, políticas de permissões, COOP/CORP, proteção contra hotlinking em navegadores compatíveis, ausência de source maps e nenhuma chave/API no frontend.

**Importante:** nenhum site público pode impedir completamente que HTML, CSS, JavaScript, textos ou imagens sejam copiados. O navegador precisa baixar esses arquivos para exibi-los. As medidas aplicadas reduzem superfícies de ataque, hotlinking e incorporação indevida, mas não prometem “anticópia” absoluta.
