# Instituto Aline Braga — Site institucional

Site estático premium desenvolvido em HTML, CSS e JavaScript Vanilla, com servidor Python opcional para testes locais.

## Abrir
- Modo simples: abra `index.html` no navegador.
- Com Python: execute `python serve.py` e acesse `http://localhost:8000`.

## Estrutura
- `index.html` — página principal, SEO e Schema.org
- `assets/css/styles.css` — UI, responsividade e animações
- `assets/js/script.js` — menu, scroll reveal, parallax, FAQ, lightbox e microinterações
- `assets/images/` — imagens otimizadas em WebP
- `robots.txt` / `sitemap.xml` — SEO técnico

## Antes de publicar
1. Confirme o domínio e ajuste `canonical`, Open Graph, `robots.txt` e `sitemap.xml` caso o endereço final seja diferente.
2. Confirme se o telefone (27) 99580-0788 também deve ser usado como WhatsApp.
3. Confirme os horários de atendimento e adicione-os somente quando houver informação oficial completa.
4. Caso tenha a logomarca oficial em PNG/SVG com transparência, substitua o monograma textual para manter a identidade original.
5. Revise os nomes dos tratamentos e quaisquer restrições ou orientações profissionais antes da publicação definitiva.

## Hospedagem
Funciona em GitHub Pages, Netlify, Cloudflare Pages, Vercel estático ou hospedagem convencional.
